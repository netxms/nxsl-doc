[[class-powerdomain]]
=== PowerDomain

[.version-added]
Added in version 7.0

Object represents power domain - segment of power distribution path within a <<class-facility>> (grid entry, generator, UPS, PDU, busway). Can be nested under another power domain. Extends <<class-datacollectiontarget>>.

==== Instance attributes

include::_shared/netobj-attrs.adoc[]

include::_shared/datacollectiontarget-attrs.adoc[]

[.attr-list]
--
[[powerdomain-autoBindScript]]
autoBindScript: <<class-string,String>>::
Source of the script for automatic binding.

[[powerdomain-isAutoBindEnabled]]
isAutoBindEnabled: bool::
Indicate if automatic binding is enabled.

[[powerdomain-isAutoUnbindEnabled]]
isAutoUnbindEnabled: bool::
Indicate if automatic unbinding is enabled.

[[powerdomain-domainType]]
domainType: int::
Power domain type as one of the <<powerdomain-domain-types,numeric values>>.

[[powerdomain-domainTypeName]]
domainTypeName: <<class-string,String>>::
Symbolic name of power domain type (`GRID_ENTRY`, `GENERATOR`, `UPS`, `PDU`, `BUSWAY`, or `OTHER`).

[[powerdomain-feedTag]]
feedTag: <<class-string,String>>::
Free-form feed label, conventionally `A` or `B`. May be empty.

[[powerdomain-ratedPower]]
ratedPower: int::
Nameplate power in watts. `0` if undeclared.
